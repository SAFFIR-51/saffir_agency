# server

서버에서만 실행되는 코드입니다. 파일 맨 위에 `import "server-only"`를 둬서
클라이언트 컴포넌트에서 import하면 빌드가 실패하게 막습니다.

- `auth/` 세션 확인 (saffirgeo + 포털 통합 로그인)
- `core/` 중앙 코어 서버 API (고객사 인스턴스 상태·사용량)
- `payments/` 토스페이먼츠 (단건 결제, 빌링 자동결제, 변동 청구)
- `db/` 사이트 DB 접근 (회원, 프로젝트, 청구)

features는 여기 함수를 호출만 하고, 외부 API 주소나 비밀키는 여기 밖으로 나가지 않습니다.
