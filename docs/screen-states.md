# 상태 화면 (화면 기획 3단계)

2026-11-11 · 정상 화면 말고 진행 중, 실패, 비어 있을 때 같은 상태를 정의한다.
와이어프레임에서는 각 화면 안에 "상태" 표나 섹터로 보인다.

| 화면            | 정의한 상태                                                                                              | 보는 곳                                      |
| --------------- | -------------------------------------------------------------------------------------------------------- | -------------------------------------------- |
| GEO 무료 진단   | 입력 전, 진단 중, 결과(일부 잠금), 실패(주소 오류 / 접속 불가·시간 초과)                                 | `/geo` S4 화면 "진단 상태"                   |
| 의료광고 검사   | 입력 전, 검사 중, 위험 표현 있음 / 없음, 무료 횟수(월 5회) 초과, 실패                                    | `/geo/ad-check` S4 화면 "검사 상태"          |
| 결제 완료       | 결제 내용(상품·금액·결제 수단·승인 시각·주문 번호), 영수증, 다음 행동(구독 → 포털 GEO, 단건 → 청구·결제) | `/order/complete` (토스 successUrl)          |
| 결제 실패       | 결제창 닫음, 한도·잔액 부족, 카드사 거절, 일시적 오류 → 다시 결제 / 문의                                 | `/order/fail` (토스 failUrl)                 |
| 로그인          | 로그인이 필요한 화면에서 옴, 로그인 시간 지남, 입력 불일치, 여러 번 틀림                                 | `/login` S4                                  |
| 비밀번호 찾기   | 이메일 입력, 보낸 뒤 안내(가입 여부와 상관없이 같은 안내)                                                | `/forgot-password`                           |
| 새 비밀번호     | 링크 맞음, 링크 만료·이미 씀, 바꾸기 완료                                                                | `/reset-password`                            |
| 포털 빈 화면    | 홈, 프로젝트, 작업 보고, 요청·문의, 내 솔루션, GEO, 청구·결제 각각 "아직 없을 때" 안내와 다음 행동       | 각 포털 화면 마지막 섹터                     |
| 문의·견적       | 입력 오류(필드별), 반복 제출 제한, 접수 불가, 접수 완료(다음 절차)                                       | `/contact`, `/development/estimate` (동작함) |
| 주문서          | 상품 없음(결제 대상이 아닌 상품)                                                                         | `/order?plan=...`                            |
| 없는 주소       | 안내 + 메인·요금·포트폴리오·문의 링크                                                                    | `not-found.tsx`                              |
| 예상 못 한 오류 | 안내 + 다시 시도 + 문의                                                                                  | 공개 사이트·포털 `error.tsx`                 |

## 정할 값 (자리표시)

- 비밀번호 재설정 링크 유효 시간: `[ 30분 ]`
- 로그인 "여러 번 틀림" 기준 횟수와 잠금 시간
- 진단 예상 시간 (실제 진단 속도를 보고 정한다)
