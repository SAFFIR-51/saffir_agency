## 고칠 것

1. **메인 섹터 순서.** 지금은 세 갈래 → 무료 진단(병원) → 일하는 방식 → 진행 순서 → 보유 모듈 → 대표 사례 → 요금 → 상담. 사례가 7번째라 늦게 나온다.
   제안: 세 갈래(병원 카드 안에 "무료 진단" 바로가기) → **대표 사례** → 무료 진단 → 일하는 방식 → 진행 순서 → 보유 모듈 → 요금 → 상담.
   기획서상 무료 진단은 "병원 고객이 들어오는 입구"이고 병원 라인은 솔루션의 대표 라인이므로, 진단을 뒤로 미루지 않고 사례 바로 다음에 둔다. 업종 공통인 사례를 먼저 보여 줘 병원 쏠림을 줄인다.
2. **병원 솔루션 허브 마지막 버튼.** 패키지 섹터의 "요금 안내 보기"를 "패키지 상담"(문의 유형 미리 선택)으로 바꾸고 요금은 보조로.
3. **비즈니스 솔루션 허브에 마지막 버튼이 없다.** 마지막에 "어떤 솔루션이 맞을지 모르겠다면" 섹터 + "도입 상담"(기타 문의) 추가.
4. **포트폴리오 목록·FAQ 끝에 다음 행동이 없다.** 포트폴리오 끝에 "비슷한 것이 필요하세요?" + 견적 요청·도입 상담, FAQ 끝에 "답을 못 찾으셨나요?" + 문의.
5. **이벤트가 없는 전환 지점.** 지금 이벤트는 6개. 다음 4개 추가를 제안:
   - `ad_check_run`: 광고 검사 실행 (검사 기능 개발 때)
   - `order_started`: 주문서 진입 (plan id)
   - `payment_completed`: 결제 완료 (plan id, 금액 구간) — 결제 기능 개발 때
   - `signup_completed`: 가입 완료 (가입한 곳: geo / ad-check / direct) — 가입 기능 개발 때
     지금 붙일 수 있는 것은 `order_started`뿐이다(주문서 페이지 열림). 나머지 3개는 해당 기능이 생길 때 붙이고, 이름만 미리 등록한다.
6. **요금표가 있는 페이지 8곳에 버튼이 없다.** 요금 안내(`/pricing`)에만 상품별 버튼이 있고, GEO·병원 홈페이지·CRM·커머스 연동·ERP·AI 챗봇·맞춤 개발·견적 요청 페이지의 요금표에는 없다. 특히 견적 요청 페이지는 정찰가 패키지를 보여 주면서 결제할 방법이 없다.
   제안: 상품별 버튼 규칙(바로 결제 → 주문서, 나머지 → 상담)을 요금표 공통 기능으로 옮겨 8곳에 같은 버튼을 단다.
7. **FAQ 내용이 비어 있다.** FAQ 페이지와 각 솔루션 페이지의 FAQ 섹터 모두 질문이 0개라 역할(결정 직전 의문 해소)을 못 한다. 5단계(실제 내용 채우기)에서 서비스별 3~5개씩 채운다.
